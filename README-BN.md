# CalcSpace — Starter Project

এটি তোমার দ্বিতীয় ওয়েবসাইটের starter folder। Next.js 15 + React 19 + TypeScript দিয়ে তৈরি।

## চালু করার নিয়ম (Windows)

1. ZIP extract করে folder-টি VS Code-এ Open করো।
2. VS Code Terminal খুলে চালাও:

```bash
npm install
npm run dev
```

3. Browser-এ যাও: http://localhost:3000

## এখন যা কাজ করছে

- Basic calculator: +, −, ×, ÷, %, brackets, decimal
- Keyboard support: Enter, Backspace, Escape
- Percentage calculator
- Average calculator
- Ratio simplifier
- Recent calculation history
- Browser LocalStorage-এ history save
- CSV ও TXT export
- Responsive layout

## পরের ধাপে যা যোগ করতে হবে

- Fraction calculator
- Age calculator
- Unit converter (length, weight, temperature, area, volume)
- PDF export
- DOCX export
- History search/filter এবং individual delete
- Better expression parser ও edge-case testing
- Website icon, SEO metadata এবং final visual polish

## গুরুত্বপূর্ণ

- কোনো MySQL/Backend লাগছে না।
- History শুধু একই browser/device-এ থাকবে।
- এই starter-এ PDF ও DOCX export এখনো যোগ করা হয়নি।
- Deploy করার আগে `npm run build` চালিয়ে build check করবে।
- Project name, logo ও design পরে নিজের মতো পরিবর্তন করতে পারবে।
